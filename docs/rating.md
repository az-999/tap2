Рейтинг хранится в кешe под индексом `\App\Console\Commands\rating_calculate::getRatingDb:rating10`

Чтобы вычислить рейтинг мой в мемкеше хранится список индексов
```php
$rating_all = [
[
    'place'          => 10,
    'balance_farmed' => 10001110102313
],
];
```

тут массив в котором хранятся элементы в котором указано два значения. Первое это место, второе место, второе это баланс нафармленный.
