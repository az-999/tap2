# Лучшие практики на BACKEND

1. Не оставлять закоментированный код в main
2. перед заливкой в main, подливать изменения из него
3. По умолчанию переменная равна PROD
3. Именование контроллеров и методов для route: /<controller>/<action>. Наименование route через тире. Наименование Контроллера/Функции - CamalCase
4. БД не использовать DOUBLE и FLOAT, для адресов тона использовать HEX формат. Для цены в тонах или других валют использовать DECIMAL
